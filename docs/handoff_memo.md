# 引継ぎメモ：「まいにち行事カレンダー」プロジェクト

作成日：2026年8月10日

## 1. プロジェクト概要

### やりたいこと
新生児が生まれる前〜小学校入学までの子育てをサポートするカレンダーアプリの企画。
日本の伝統的な子育て行事（お宮参り・お食い初め・七五三など）を、基本情報（出産予定日・家族構成）から自動でカレンダーに登録し、リマインド通知する。将来的にはEC連携（鯉のぼり・ひな壇等のメーカー提携）も視野。

### 現在のフェーズ
**アプリ本体はまだ未着手。LP（ランディングページ）を使った需要検証フェーズ。**
小規模な広告出稿（Meta広告・Google検索広告）を行い、LINE公式アカウントへの事前登録数でCVRを計測する計画。

## 2. これまでの検討・決定事項

### 競合調査（済み）
- 直接競合：ベビーカレンダー、ninaruシリーズ、たまひよ等 → 情報配信は強いが「行事の自動カレンダー登録＋リマインド」は弱い
- 隣接競合：行事日付計算サイト（きものレンタリエ等）→ 日付計算のみで自動登録・通知機能なし
- 隣接競合：TimeTree等の家族共有カレンダー → カレンダー基盤は強いが行事の知識・EC連携なし
- **差別化ポイント**：「カレンダー×行事×家族共有×EC」を1本に統合したアプリはニッチが空いている

### ターゲット設定（決定済み）
- **第一子の親**（初産・初育児で行事の勝手がわからない層）
- 妊娠中〜出産までの情報は対象外（たまひよ等の独壇場のため）
- **メイン対象年齢：生まれてから2〜3歳ごろ**（行事が密集する時期）
- ロングテールで小学校入学（入学式等）までカバー

### キャッチコピー（決定済み）
**「調べなくていい。赤ちゃんの行事、全部自動登録。」**
- 理由：課題の言語化（調べる手間）と解決策（自動登録）が両方伝わるコピーとして採用

### ビジュアルトーン（決定済み）
**B案：かわいい・親しみ系** で確定
- 配色：ピーチクリーム背景 `#FFF6F2` ／ コーラルピンク `#FF8FA3` ／ ミント `#7FCCB8` ／ イエロー `#FFD684` ／ LINE公式グリーン `#06C755`（CTA）
- 書体：Zen Maru Gothic（丸ゴシック、Google Fonts）
- シグネチャー要素：行事を「成長の道のり」として見せるリボン状タイムライン

### アプリ名（決定済み）
**「まいにち行事カレンダー」**（最終決定・2回の再検討を経て確定）

決定までの経緯：
1. 初期案「すくすくノート」→ KUMON（くもん出版）の既存ブランドと同名のため却下
2. 2回目案「まいにち行事ノート」→ ①「まいにち」が実態（頻度）と合わない、②メイン機能は「ノート」ではなく「カレンダー」、という2つの指摘により再検討
3. 「おいわいごよみ」「家族ごよみ」等、お祝い事に限定しない広い名前も検討したが、**将来的にお盆・厄年・還暦など非祝い事も含めて機能拡張する予定はあるものの、ユーザー獲得の入口は恒久的に「赤ちゃんの行事で困っている人」であり続ける**という事業方針が明確になったため、名前を将来の機能範囲に合わせて広げる必要はないと判断
4. 「赤ちゃん行事カレンダー」等、直接「赤ちゃん」を含む直球な名前も検討したが、`baby.gyozi.net`という既存の行事日付計算サイトが同名を使用しており衝突するため却下
5. 最終的に「まいにち行事カレンダー」に回帰。「まいにち」は文字通りの頻度ではなく親近感を表す慣用的な言葉（例：「まいにちのお弁当」等）と割り切り、「たまひよ」ブランド（妊娠〜新生児を連想させる名前のまま幼児期まで幅広くカバーしている前例）と同様の考え方で、**名前が入口の年齢層を想起させても機能拡張の妨げにはならない**という整理で確定

**重要な事業方針（名前の背景にある前提）**：機能は将来「赤ちゃん」＋「幼児〜小学生」＋「他の家族（パパ・ママ・祖父母）」＋「お盆等の日本のしきたり」まで拡張する構想があるが、LPのキャッチコピー「調べなくていい。赤ちゃんの行事、全部自動登録。」およびユーザー導入（マーケティング上のターゲティング）は恒久的に「赤ちゃんの行事」に焦点を当て続ける方針。名前とキャッチコピーの役割分担は、名前＝サービスの温度感、コピー＝具体的なターゲットと便益、と整理されている。

### CTA導線（決定済み）
LINE公式アカウントへの友だち登録に一本化（メールフォームは不使用）

## 3. 作成済みの成果物

以下、すべて `/mnt/user-data/outputs/` に出力済み（Cursor側では該当プロジェクトフォルダにコピーして管理する想定）。

| ファイル名 | 内容 |
|---|---|
| `lp_cute.html` | **本命のLP**（かわいい・親しみ系トーン、確定版）。ヒーロー／課題提起／機能紹介／行事タイムライン／家族共有／共感セクション／登録後の流れ／FAQ／プライバシー導線／最終CTAで構成 |
| `lp_simple.html` | 不採用のシンプル・実用系トーン案（比較用に保持、以後は使わない想定） |
| `privacy.html` | プライバシーポリシー（β版・事前登録段階向けの簡易版） |
| `about.html` | 運営者情報（所在地等は「準備中」のプレースホルダー） |
| `contact.html` | お問い合わせフォーム（見た目のみ、送信機能は未実装） |

### lp_cute.html の主要セクション構成（上から順）
1. ヘッダー（ロゴ＋LINE登録CTA、モバイル420px以下でレスポンシブ調整済み）
2. ヒーロー（キャッチコピー＋スマホ内カレンダーのビジュアル）
3. 課題提起（「それ、いつやるんだっけ？」）
4. 機能紹介3点（自動登録／リマインド／家族共有）
5. 行事タイムライン（お七夜〜入学式までのリボン表現）
6. 家族共有セクション（ママ・パパ・祖父母のアバター表現）
7. **共感セクション**（旧「対応期間」表記から変更済み。「生後〜2・3歳ごろは、はじめての行事がいちばん続く時期」という当事者目線の共感コピー＋3つの困りごとバブル＋「七五三や入学準備まで、長く寄り添います」の軽い一文）
8. 登録後の流れ（3ステップ：登録完了メッセージ→行事コラム配信→アプリ先行案内）
9. **β版である旨の注記**（アプリ本体は開発準備中、現状はLINE配信のみである旨を正直に明記）
10. FAQ（5項目：費用／今使えるか／第一子以外でも良いか／地域差対応／配信停止方法）
11. プライバシー文言（機微情報の利用目的を明示する短いバンド）
12. 最終CTA

### 表現修正の経緯（重要・やり直し防止のため記載）
- 当初「対応期間：生まれてから、小学校入学まで」＋進捗バーで表現していたが、これは**運営側のターゲティング戦略がそのままユーザー向けコピーに漏れていた**ため、ユーザー視点の共感コピーに全面差し替え済み。今後この手のセクションを作る際は「サービス範囲の説明」ではなく「ユーザーの困りごとへの共感」を優先すること。
- CTA文言「ずっと無料でつかえます」は、FAQの「アプリ本体の料金プランは今後決定」という回答と矛盾するため、「事前登録・情報配信は無料です」に修正済み。**今後、料金に関する表記を追加する際はFAQとの整合性に注意。**

## 5. 技術メモ（Cursorでの作業向け）

- LPは素のHTML/CSS（フレームワーク不使用）、Google Fonts（Zen Maru Gothic）を`<link>`で読み込み
- レスポンシブ対応済み（420px以下で見出し・ボタンサイズを縮小するmedia queryあり）
- 画像は使用せず、絵文字とCSSによる装飾のみで構成（軽量・依存ライブラリなし）
- フォーム（お問い合わせページ）は見た目のみで送信処理は未実装。実際の送信機能（メール送信 or 外部フォームサービス連携）を今後実装する必要あり
- 各HTMLファイル内のロゴ・タイトル・footer表記は「まいにち行事カレンダー」に統一済み（「すくすくノート」→「まいにち行事ノート」→「まいにち行事カレンダー」の順で一括置換を実施、最終確定版）

## 6. 参考：不採用となった案（記録として）

- LPキャッチコピー案A「お宮参りって、いつ行けばいいんだっけ？」等（不安訴求型）→ B案採用後、保留
- ビジュアルトーンA（シンプル・実用系）→ B案採用のため不使用（`lp_simple.html`として保持のみ）
- アプリ名候補の検討過程（不採用分）：
  - 「すくすくノート」→ Kumonと同名のため却下
  - 「おいわいノート」「コトホギノート」「そだちごよみ」→ 「ノート」表記の見直しの過程で不採用
  - 「まいにち行事ノート」→ 「ノート」ではなく「カレンダー」が実態に合うため不採用
  - 「おいわいごよみ」「家族ごよみ」「くらしごよみ」「くらしの行事カレンダー」「かぞくの行事カレンダー」「家族の行事カレンダー」→ 将来の非祝い事（厄年・お盆等）まで含めた命名を検討する過程で候補に挙がったが、「ユーザー獲得の入口は恒久的に赤ちゃんの行事」という事業方針の明確化により、広い名前にする必要がないと判断し不採用
  - 「赤ちゃん行事カレンダー」→ 既存の行事日付計算サイト（baby.gyozi.net）と同名のため却下
- **最終決定：「まいにち行事カレンダー」**（詳細な決定経緯は上記セクション参照）
