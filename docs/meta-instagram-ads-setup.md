# Meta / Instagram 広告出稿手順（GYOJI-CHO・需要検証）

ゴール: **Instagram広告 → LP → LINE友だち追加 → 事前登録フォーム** の反応を小予算で見る。

| 項目 | 値 |
|---|---|
| LP（必須） | `https://gyoji-cho.pages.dev/?ch=meta` |
| 計測 | `?ch=meta` ＋ LINE経路 `lp-meta`（Pixelは後回し可） |
| 配置 | まずは **Instagram中心**（フィード／ストーリーズ／リール） |
| 予算目安 | 日額 **1,000〜3,000円**、期間 **7〜14日** |
| 見るKPI | LP訪問、CTAクリック、LINE友だち追加、フォーム完了 |

**広告のリンク先に `lin.ee` を直接貼らない。** 必ず LP（上記URL）にする。

## 0. 事前に用意するもの

- [ ] Meta Business Suite / ビジネスマネージャ
- [ ] 広告アカウント（支払い方法登録済み）
- [ ] Facebookページ（広告の「名義」用。なければ新規作成可）
- [ ] Instagram（プロアカウント）をページに連携
- [ ] クリエイティブ用画像 or 短尺動画（後述）

まだの場合の入り口:

1. [business.facebook.com](https://business.facebook.com/) でビジネス管理
2. [adsmanager.facebook.com](https://adsmanager.facebook.com/) で広告マネージャ

## 1. キャンペーン

広告マネージャ → **作成**

| 項目 | 推奨 |
|---|---|
| 目的 | **トラフィック**（サイト誘導。Pixelなしの検証向き） |
| キャンペーン名例 | `GYOJI-CHO_IG_traffic_beta_YYYYMM` |
| A/Bテスト | オフで開始 |
| Advantage キャンペーン予算 | オフ（広告セットで日額を固定）でも可 |

※ Pixel を入れて友だち追加をコンバージョンにできるようになったら、後日「リード／売上」系に切り替え検討。初回はトラフィックで十分。

## 2. 広告セット

| 項目 | 推奨 |
|---|---|
| コンバージョンの場所 | **ウェブサイト** |
| 最適化対象 | **ランディングページビュー**（なければリンククリック） |
| 予算 | 日額 1,000〜3,000円 |
| スケジュール | 7〜14日 |
| 地域 | 日本 |
| 年齢 | **22〜40** くらい（第一子想定。絞りすぎない） |
| 性別 | 最初は **女性寄り**、または両方で様子見 |
| 詳細ターゲット | 興味関心例: 妊娠・出産、育児、ベビー、マタニティ、子育て など（画面の候補から近いものを複数） |
| 配置 | **手動** → Instagram（フィード・ストーリーズ・リール）にチェック。Audience Network は外す |

オーディエンスが狭すぎると配信されないので、興味関心は 2〜4 個程度から。

## 3. 広告（クリエイティブ）

| 項目 | 推奨 |
|---|---|
| Facebookページ / Instagram | 連携済みアカウントを選択 |
| フォーマット | シングル画像（または短い縦動画） |
| ウェブサイトのURL | **`https://gyoji-cho.pages.dev/?ch=meta`** |
| CTAボタン | **詳しくはこちら** または **今すぐ登録** |

### テキスト案（B案トーン）

**メインテキスト例:**

```
お宮参りって、いつだっけ？
お食い初めの準備、間に合うかな…。

はじめての育児だと、そんなことが次々に出てきますよね。

まいにち行事カレンダーは、出産予定日を教えるだけで
行事の目安とミニコラムをお届けします。

いまは事前登録受付中（無料）。
カレンダーアプリは準備中です。
```

**見出し例:**

```
調べなくていい。赤ちゃんの行事、全部自動登録。
```

**説明（任意）:**

```
LINEで30秒登録。事前登録・情報配信は無料です。
```

### 画像の目安

- サイズ: 1080×1080（フィード）または 1080×1920（ストーリーズ／リール）
- LPと同系: ピーチクリーム背景、コーラルピンク、丸みのある雰囲気
- 文字入れする場合は短く: 「お宮参り、いつだっけ？」＋サービス名
- 医療・恐怖訴求は避ける（B案）

素材がまだなければ、Canva 等で上記トーンの静止画を1枚作って開始で可。

## 4. 公開前チェック

- [ ] URLに **`?ch=meta`** が付いている
- [ ] プレビューで Instagram 表示が崩れていない
- [ ] LPの about に「準備中」があることを許容した小規模検証である
- [ ] 審査用に、誘導先が実在し、誇大（「必ず間に合う」等）になっていない

**公開** → 審査通過を待つ（数時間〜1日程度のことが多い）。

---

## 5. 計測の見方（Pixelなし）

| 指標 | どこで見る |
|---|---|
| 広告クリック / CPC | Meta広告マネージャ |
| LP到達 | MetaのLPビュー（あれば）＋感覚的にはクリックと友だち増の差 |
| LINE友だち追加（Meta経路） | LINE公式の追加経路 `lp-meta`、またはエルメの友だち一覧 |
| フォーム完了 | エルメのフォーム回答数 |

成功のざっくり目安（検証）:

- クリック → LINE追加の率が極端に低くないか
- 追加 → フォーム完了まで落ちすぎないか

数字が溜まったら、クリエイティブ差し替え or ターゲティング調整。

---

## 6. あとでやる（必須ではない）

- Meta Pixel を LP の `index.html` に埋め込み
- カスタムコンバージョン（例: サンクス相当のURLは無いので、現状は LINE 側照合が中心）
- Google検索広告（`?ch=google`）

## つまずきやすい点

- Instagramだけ出したいのに Advantage+ 自動配置のまま → **手動配置**にする
- リンク先が `lin.ee` → **必ず pages.dev/?ch=meta**
- オーディエンスが狭すぎて「学習しない／配信されない」→ 年齢・興味を少し広げる
