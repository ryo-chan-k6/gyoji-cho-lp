# こどもと季節 Visual Character Guide

最終更新: 2026-08-15

## 1. 本ドキュメントの目的

Instagramメディア「こどもと季節｜親子で楽しむ日本の行事」で使用する親子キャラクターについて、今後Reels・プロフィール画像・静止画素材等をAIで継続的に量産しても、**同じブランドの親子として認識できる再現性**を確保するための基準を定める。

本書は、現時点で採用した**第1デザインパターン（Visual Pattern 01）**のCharacter Bibleである。

> **Status: Baseline / Pattern 01**
>
> 現時点の第1基準案として採用する。運用開始後のユーザー反応や、実際の画像生成時の再現性を見てアップデートしてよい。

---

## 2. Visual Pattern 01 のコンセプト

### コンセプト

> **スマホで見る、小さな絵本・紙芝居。**

「こどもと季節」のビジュアルは、写実的な家族イラストや一般的なAI育児イラストではなく、**紙芝居・絵本のような手描きの温かさと、キャラクターとしての記憶性**を重視する。

目指す印象:

- かわいらしい
- 親しみやすい
- 手描きの温かさがある
- 少し不完全で、人の手で描いたように感じる
- 子ども向けすぎず、親が見ても好きになれる
- 行事・季節を押し付けず、「ちょっとやってみよう」と思える
- 一目で「あの親子のアカウント」と認識できる

避ける印象:

- 一般的な生成AIの「優しいママと子ども」素材
- 写実的・フォトリアル
- 3Dキャラクター
- 光沢の強いデジタルアニメ塗り
- 整いすぎた美男美女
- 特定の既存アニメーションスタジオ・作家の模倣
- 幼児教材に寄りすぎた単純な子ども向け表現

## 3. イラストスタイル

### STYLE-01: 手描き絵本・紙芝居タッチ

基本は、これまで検討したC4系統の**落書き感・手描き感のある絵本タッチ**をベースとする。

描画要素:

- 色鉛筆 + クレヨン + 不透明水彩（ガッシュ）を組み合わせたような質感
- 紙の繊維・ざらつきをわずかに感じる背景
- 輪郭線は均一なベクター線にせず、わずかに揺らぐ
- 塗りは完全に均一にせず、手塗りのムラを少し残す
- 左右対称・完全な形にしすぎない
- キャラクターは現実より強くデフォルメする
- 背景は細密に描き込みすぎず、紙芝居のように主題が一目で分かる構図
- Reelでは1カットごとに「1枚の絵本・紙芝居」として成立させる

### 構図の基本

プロフィール画像や代表ビジュアルでは、親子の関係が小さい表示でも読めるようにする。

基本構図:

```text
季節を象徴する大きなモチーフ
（月・桜・紅葉・雪など）
          ↑
      子どもの視線 / 指差し

  CHILD-01     MOM-01
      親子で同じ対象を体験
```

「親が子どもへ一方的に教える」よりも、**親子が一緒に発見・体験している状態**を優先する。

## 4. 子どもキャラクター

### ID

**CHILD-01**

### 基本設定

| 項目 | 基準 |
|---|---|
| 年齢感 | 2〜3歳程度 |
| 性別 | 男の子 |
| 頭身 | 約2〜2.5頭身。強めのデフォルメ |
| 顔 | 大きく丸い顔 |
| 前髪 | **ぱっつん前髪**を最重要識別要素とする |
| 髪 | 濃い茶色。シンプルな丸いシルエット |
| 目 | 小さくシンプル。写実的な瞳・強いハイライトは使わない |
| 鼻 | 点・短い線程度に簡略化 |
| ほっぺ | 大きめの丸い赤み。キャラクター識別要素 |
| 口 | 小さく単純。笑顔では大きめに開いてもよい |
| 体 | 頭に対して小さく、手足は短め |
| 基本服 | 山吹色 / マスタード系トップス |
| ボトム | くすんだ緑・オリーブ系 |

### キャラクター性

CHILD-01はブランド内で最も視覚的な主役とする。

想定する性格・表情:

- 好奇心が強い
- 季節のものを見つけてすぐ指差す
- 「これなに？」という表情
- 楽しい時は大きく笑う
- 不思議なものを見ると目を丸くする
- ときどき夢中になり、親より先に行動する

### 必須の識別特徴

次の4点はシーンが変わっても原則維持する。

1. **ぱっつん前髪**
2. **大きく丸いほっぺ**
3. **大きな頭 + 小さな体のデフォルメ**
4. **山吹色 / マスタード系をキャラクターカラーとして使用**

これらを維持することで、小さなプロフィール画像やReelの短いカットでもCHILD-01と認識できる状態を目指す。

## 5. ママキャラクター

### ID

**MOM-01**

### 採用デザイン

検討したママデザインM1〜M3のうち、**M3「小さなおだんごのママ」**をVisual Pattern 01として採用する。

### 基本設定

| 項目 | 基準 |
|---|---|
| 年齢感 | 30歳前後 |
| 頭身 | 約4〜4.5頭身。成人としては強くデフォルメ |
| 顔 | 丸みのある卵型。美人顔よりキャラクター性を優先 |
| 髪 | 濃い茶色 |
| 髪型 | **後頭部〜やや低め位置の、小さく丸いおだんご** |
| 前髪 | 顔周りに自然な短い毛束。整えすぎないが、ぼさぼさにはしない |
| 後れ毛 | 1〜2本程度を意図的に配置。毎回大量に出さない |
| 目 | 小さくシンプル。子どもと同じ造形言語 |
| 鼻 | 小さく簡略化 |
| ほっぺ | 淡い赤みを付け、子どもとの親子感を持たせる |
| 基本服 | 生成り / アイボリー系のシンプルなトップス |
| 役割 | 子どもと同じ対象を楽しむ伴走者 |

### キャラクター性

- 「何でも知っている先生」にはしない
- 子どもの発見を一緒に楽しむ
- ときには行事準備に困る・迷う普通の親として描く
- 子どもを見る時に少し首を傾ける等、柔らかい仕草を使う
- きれいすぎる育児広告の母親ではなく、絵本キャラクターとして親しみを持たせる

### 必須の識別特徴

1. **小さく丸いおだんご**
2. **大人としては強めのデフォルメ（4〜4.5頭身）**
3. **生成り / アイボリー系の基本服**
4. **子どもと共通する丸いほっぺ・簡略化された目鼻**

MOM-01単体を写実的に描かず、常にCHILD-01と同じ世界のキャラクターに見えることを優先する。

## 6. 親子の造形ルール

### 視覚的な主従

```text
CHILD-01 = Primary Character
MOM-01   = Supporting Character
季節・行事 = Story Theme
```

子どもが最も視覚的に印象へ残り、ママは親子関係と体験の安心感を作る。

### 親子感を出す共通言語

- 丸い顔・頬
- シンプルな小さい目鼻
- 少し揺れる手描き線
- 完全な左右対称を避ける
- デフォルメされた身体
- 温かい低〜中彩度の配色

ただし、親子の髪型や顔を完全に同じにはしない。

---

## 7. 基本カラーパレット

色は完全固定値ではなく、手描きの色ムラを許容する。

| 用途 | 色の方向性 |
|---|---|
| 月・温かい光 | 黄・山吹 |
| 夜空 | 深い紺 |
| CHILD-01の基本服 | 山吹 / マスタード |
| CHILD-01ボトム | オリーブ / くすみ緑 |
| MOM-01の基本服 | 生成り / アイボリー |
| ほっぺ | くすみピンク / サーモン |
| すすき・木 | ベージュ / 茶 |
| 雲・冬 | ブルーグレー |
| 植物 | くすみ緑 |

季節に応じてアクセントカラーを変える。

- 春: 桜色、淡い緑
- 夏: 青緑、空色
- 秋: 山吹、橙、茶
- 冬: 淡い青、生成り、赤

キャラクターの識別色は季節色より優先する。

## 8. 固定する要素 / 可変にする要素

### 原則固定

- CHILD-01の顔・ぱっつん前髪・頭身・ほっぺ
- CHILD-01の基本カラー
- MOM-01の顔の造形言語
- MOM-01の小さなおだんご
- MOM-01のデフォルメ比率
- STYLE-01の線・紙・塗りの質感
- 親子の世界観

### シーンに応じて変更可能

- 表情
- ポーズ
- 視線
- 季節背景
- 行事小物
- 防寒着・浴衣・七五三等のイベント衣装
- カメラ位置
- 構図
- 時刻
- 季節アクセントカラー

### 衣装を変える場合

イベント衣装を着せても、以下のどれかを残して同一キャラクターと分かるようにする。

- CHILD-01: ぱっつん前髪 + 丸いほっぺ
- MOM-01: 小さなおだんご + 顔の造形

## 10. 代表プロフィール画像

Visual Pattern 01の代表プロフィール画像は、**親子で月を見るシーン**を基本構図とする。

構成:

- 夜空の大きな黄色い月
- すすき等、季節を感じる最小限の背景
- CHILD-01が月を指差す
- MOM-01が子どもと一緒に月を見る
- 円形トリミング時にも親子・月が明確に残る
- 文字・ロゴは入れない

プロフィール画像単体で「日本の行事」を説明しすぎず、**親子 × 季節 × 発見・体験**を象徴する。

## 11. Reelへの展開

Reelsはキャラクターを動かすアニメーション作品に限定せず、**同じ親子を描いた複数の絵本・紙芝居カットをテンポよく見せる形式**を基本候補とする。

例: 十五夜

```text
CUT 1
CHILD-01が空を見上げる
「今週、これやってみない？」

CUT 2
月を指差すCHILD-01 + MOM-01
「もうすぐ十五夜」

CUT 3
親子で月を見る
「お団子を作らなくても大丈夫」

CUT 4
笑顔の親子
「一緒に月を見るだけでも。」
```

毎カットでキャラクターの造形を作り直さず、同じCharacter Referenceを使用する。

## 12. AI生成時の必須ルール

AIへ画像生成を依頼する際は、テーマだけで生成せず、必ず次の順で指定する。

```text
1. STYLE-01
2. CHILD-01 character reference
3. MOM-01 character reference
4. 今回の季節・行事
5. シーン・構図
6. 表情・ポーズ
7. 使用目的 / アスペクト比
```

### 基本生成指示テンプレート

```text
「こどもと季節」のVisual Pattern 01として描く。

STYLE-01:
紙芝居・絵本のような温かい手描きタッチ。
色鉛筆、クレヨン、不透明水彩を組み合わせたような質感。
少しざらついた紙、わずかに揺れる輪郭線、手塗りの色ムラ。
写実的・3D・光沢の強いデジタルアニメ表現にはしない。

CHILD-01:
2〜3歳の男の子、約2〜2.5頭身。
大きな丸顔、ぱっつん前髪、濃い茶色の髪、丸い赤いほっぺ、
小さく単純な目と鼻、短い手足。
基本服は山吹色・マスタード系。

MOM-01:
30歳前後、約4〜4.5頭身にデフォルメ。
丸みのある顔、小さな目鼻、淡い丸いほっぺ。
濃い茶色の髪を後頭部の低め位置で小さく丸いおだんごにまとめる。
髪は整っているが、1〜2本の自然な後れ毛を残す。
基本服は生成り・アイボリー。

親が教える構図より、親子が同じものを一緒に発見・体験している構図にする。

SCENE:
[ここに今回の具体シーンを記載]
```

### Negative / Avoid

次は明示的に避ける。

- photorealistic
- realistic adult proportions
- glossy digital anime rendering
- 3D render
- perfect symmetrical face
- highly detailed realistic eyes
- beauty-advertisement-like mother
- generic stock illustration look
- excessively detailed hair
- excessive loose hair / messy bun
- child with long realistic limbs
- character design changes between cuts
- specific existing studio / artist imitation

## 13. 生成後のConsistency Check

公開素材として使用する前に、最低限以下を確認する。

### CHILD-01

- [ ] ぱっつん前髪か
- [ ] 丸いほっぺが維持されているか
- [ ] 2〜2.5頭身程度か
- [ ] 顔・身体が写実的になっていないか
- [ ] CHILD-01として前回素材と同一人物に見えるか

### MOM-01

- [ ] 小さなおだんごか
- [ ] 髪がぼさぼさ・過度な後れ毛になっていないか
- [ ] 成人のリアル頭身に戻っていないか
- [ ] AI生成にありがちな整いすぎた美人顔になっていないか
- [ ] CHILD-01と同じ絵本世界の人物に見えるか

### STYLE

- [ ] 紙・画材の手描き感があるか
- [ ] デジタル的に整いすぎていないか
- [ ] 季節モチーフが一目で認識できるか
- [ ] 小さい画面でもキャラクターと主題が判別できるか
