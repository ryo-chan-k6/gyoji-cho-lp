# Decision Record: `D-020 Phase 0の費用上限`

- 状態：Decided
- 決定日：2026-08-16
- 決定者：責任者
- 見直し日：Phase 0 Gate時
- 見直し条件：追加支出なしではPhase 0 Gateを満たせない事実が判明した場合
- 置き換える判断：なし

## 決めること

Phase 0の追加支出上限、外注、既存サービス、広告費との境界を固定する。

## 決定

- Phase 0の **追加支出上限を0円**とする
- 本プロジェクトでは **外注を行わない**
- 現在契約中のAIエージェントサービス等を既存契約の範囲内で利用する
- Phase 0で新しい有料ツール、調査サービス、素材、外部専門家を購入しない
- 広告費はPhase 0に含めず、Phase 0.5の `D-010` で扱う。現時点の予算想定は約5,000円だが、本判断では `D-010` 全体を確定しない
- App Store公開に必要なApple関連費用は `D-012` とPhase 1予算で別途扱う
- 想定外の追加費用が必要になった場合は支出せず、新しい判断または本D-IDの改定を責任者へ提示する

## 背景と制約

Phase 0は事業仮説、MLPスコープ、計測、Legal、Validation基準を文書とレビューで固定する段階である。既存のAIエージェントサービスとリポジトリ環境で実行でき、外注や新規有料ツールを必要としない。

## 検討した選択肢

| 選択肢 | 利点 | 欠点・リスク | 採否 |
|---|---|---|---|
| 追加支出0円・外注なし | コストを最小化し、既存環境で仮説を固定できる | 専門家確認が必要な場合は別判断が必要 | 採用 |
| 3万円の追加費用枠 | 突発的な有料調査へ対応できる | 必要性が未確認の予算を確保する | 不採用 |
| 外注を含む予算枠 | 専門作業を移管できる | 運営方針と責任者の意向に合わない | 不採用 |

## 根拠と不確実性

- 根拠：Phase 0の成果物は既存AIサービスと責任者稼働で作成可能
- 不確実性：Phase 1のApple関連費用、Phase 0.5の広告設計、法的専門家確認の必要性
