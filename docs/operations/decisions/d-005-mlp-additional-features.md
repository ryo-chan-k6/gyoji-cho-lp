# Decision Record: `D-005 MLP追加候補`

- 状態：Decided
- 決定日：2026年8月16日
- 決定者：責任者
- 見直し日または見直し条件：Phase 2 / 2.5の結果からD-004のCore / Extended Valueが支持され、正式v1の計画を作る時点。付加機能の欠如がCore到達・継続を阻害していると行動・定性の複数証拠から示唆された時点。または、付加機能がないことでP1 Usability TestのCore path完了を妨げる重大な問題が確認された場合
- 置き換える判断：なし

## 決めること

Appleカレンダー連携、簡易共有、体験記録、ウィジェットをiOS Validation Releaseへ含めるかを決める。

## 決定

推奨案Aを採用し、次の4機能はすべてValidation Releaseの**Won't**とする。

1. Appleカレンダー連携
2. 簡易共有
3. 体験記録
4. ウィジェット

これらの入口、空の画面、将来予告、権限要求、AnalyticsイベントもValidation Releaseへ実装しない。App Store、広告、LPでも提供中機能として訴求しない。

D-004でMustとしたアプリ内の簡易時系列、ホーム「つぎのお祝い」、ローカル通知、行事・季節文化の選択状態、準備チェックリストは維持する。Appleカレンダー連携を除外しても、アプリ内で予定を確認・調整できる状態を成立させる。

## 背景と制約

- Validation Releaseの目的は、個別化された行事生成、意味理解、家庭の判断、準備、通知、季節文化という価値連鎖の検証である
- 付加機能を同時に入れると、Core Valueと便利機能の効果を分離しにくい
- Appleカレンダー連携は、追加・更新・重複・削除・権限・同期失敗の設計とQAが必要になる
- 簡易共有は、共有内容、個人情報、第三者権利、共有先での表示保証の検討が必要になる
- 体験記録は、写真・メモ・保存・削除・移行等へScopeが広がりやすい
- ウィジェットは、OS別表示更新、機密表示、通知との重複、追加QAが必要になる
- D-004のMustだけで、MLPのCore / Extended Valueは途中で切れない

## 検討した選択肢

| 選択肢 | 利点 | 欠点・リスク | 採否 |
|---|---|---|---|
| A. 4機能をすべてWon't | D-004のMustと主要仮説へ開発・QAを集中できる | 外部カレンダー、家族共有、記録等を期待する人には機能不足 | 採用 |
| B. Appleカレンダー連携だけを含める | 既存予定と一緒に管理でき、アプリ名との期待に合いやすい | 同期・重複・削除の負荷が大きく、アプリ内通知との価値分離が難しい | 不採用 |
| C. 簡易共有だけを含める | 家族の意思決定を支援しやすい | 個人情報・共有文言・共有先QAが増え、Primary User本人の価値検証を遅らせる | 不採用 |
| D. 体験記録またはウィジェットを含める | 愛着・再訪・視認性を強化できる可能性 | Core Valueとは別仮説で、保存・表示更新等の実装負荷が増える | 不採用 |

## 再評価の条件

正式v1で再評価する場合、便利そうという理由だけで戻さず、各機能について次を満たす。

- Phase 2 / 2.5の利用・離脱理由から解くべき課題が特定されている
- 「欲しい」という機能要望や誘導質問への回答だけを採用根拠にしない
- 現在の代替行動・回避策、実際に完了できなかったJob、App Store等での期待差、非要望者・継続者の反例を収集する
- 行動証拠と定性証拠の複数から、付加機能の欠如がCore到達・継続の阻害要因である可能性を確認する
- D-004のCore pathを弱めない
- 機能固有の仮説、観測方法、成功・失敗条件がある
- 追加のPrivacy、権限、データフロー、第三者権利、QA工数を見積もれる
- 正式v1の開発上限内に収まる

阻害要因が示唆されても正式v1へ自動追加しない。D-005を再度Human判断へ戻し、機能固有仮説を持つPivot / 再検証候補として、必要に応じ比較可能な検証を先に行う。Phase 2では4機能の因果効果を主張しない。

## 根拠と不確実性

- 根拠：`P0-PROD-03`では4機能をCore path外の付加価値入口として分離している
- 根拠：`D-004`で、4機能がなくても成立するホーム、時系列、通知、判断・準備体験をMust化した
- 不確実性：Appleカレンダー連携や家族共有が、実際にはInstall後の継続利用へ強く影響する可能性がある
- 不確実性：アプリ名に「カレンダー」を含むため、外部カレンダー同期を期待する利用者がいる可能性がある
- 不確実性：Phase 2では除外機能の因果効果を検証できず、定性調査で要望・離脱理由を探索するに留まる
