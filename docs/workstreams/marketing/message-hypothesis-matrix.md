# Message Hypothesis Matrix

- Task ID：`P0-MKT-02`
- 版：v1.0（Product Lead Review済み）
- 更新日：2026年8月16日
- 入力：[`Audience / Occasion Matrix`](audience-occasion-matrix.md)、[`Assumption / Evidence Register`](../validation/assumption-evidence-register.md)

## 目的と制約

Phase 0.5で「どの問題表現・価値表現ならPrimary Userに伝わりやすいか」を比較するため、広告フックからLPの受け、期待されるプロダクト体験、反証条件までを一続きの仮説として定義する。

- Phase 0.5は**広告メッセージ検証**であり、アプリ需要、Product Value、Retention、収益性を判定しない
- 下記はコピー候補を作るための仮説であり、正式コピー、媒体、予算、配信対象、LP構成の決定ではない
- 広告反応は訴求間の相対的な伝わりやすさの手掛かりに限り、`P-01〜04`や`V-01〜06`の支持証拠へ転用しない
- 行事名は利用場面の例であり、`D-002/003`によるMLP採用を先取りしない
- 妊娠期流入と出生後流入は同一の反応母集団として集計しない

| `M-01` 赤ちゃん行事の見通し | 妊娠後期。出産後の行事全体像をまだ把握していない | 出産後すぐの行事と準備開始時期が見えず、先回りできない | 子どもの時期に応じて、これからの行事を見通せる | 「赤ちゃんが生まれたら、次の行事はいつ？」／「出産後の行事を、今から見通す」 | 妊娠期に得られる出産後行事の見通し、一般的目安、出生後も価値が続く構想。現在提供中／将来提供を明確に分け、入力・更新方法は`D-004`で採用するまで約束しない | 妊娠期から出生後へ行事の見通しを継続する。予定日入力・出生情報更新等の実現方法は`D-004`採用時のみ具体化する | 妊娠期セグメント内で他訴求より相対的に理解・反応され、LPでも見通し価値への関心が一貫する | 反応が低い、または「妊娠・育児全般の情報」と誤認される。比較可能な母数不足は保留 | 出生前に全日程が確定する、医療・発達情報も提供するとの誤認 |

| `M-03` 準備・家族判断の支援 | 出生後1〜11か月。実施意向のある行事が近づいている | 日付だけ分かっても、参加者・場所・写真・衣装・食事等をいつ決めるか整理できない | 行事までの残り期間に合わせ、家族で決めることと準備の順番が分かる | 「行事の日付だけでなく、準備まで」／「次に決めることを、先回り」 | 意味理解→家庭での判断→準備の順序。予約・購買は将来像とし、未提供の提携先があるように見せない | 行事詳細→行事をどう扱うかの判断→準備情報→後続行動 | 行事が近い・実施意向のある層で相対的に反応され、LPで準備支援への関心が一貫する | 行事意向がない層を含めると比較不能。リスト管理アプリや予約サービスとの誤認が支配的なら反証 | 予約代行、在庫保証、提携済み事業者、準備完了の保証があるとの誤認 |

## 比較単位と読み方

| 比較観点 | 事前に分ける単位 | Phase 0.5で読めること | 読めないこと |
|---|---|---|---|
| 訴求 | `M-01〜04` | 同条件に近づけた場合の相対的なメッセージ反応 | アプリを継続利用する需要、Product Value |
| 流入時期 | 妊娠期／出生後 | 各時期で理解されやすい入口の違い | 妊娠期流入者の出生後Retention |
| 行事緊急度 | 目前／将来 | 緊急度と問題表現の組合せによる反応差 | 行事準備が実際に完了する効果 |
| ファネル | 表示→広告反応→LP到達→LP内行動 | 広告とLPの約束が途中で崩れていないか | Install、Activation、準備行動、購買意向 |

実際の比較対象、母数、期間、クリエイティブ形式、変更・停止ルール、統計的な扱いは`P0-MKT-04`、`P0-DATA-04`、`P0-VAL-02`および`D-010`で事前固定する。母数不足、配信条件差、計測欠損がある結果は、勝敗を付けず「不明」とする。

## LPと将来Productへの受け渡し原則

1. 広告で提示した問題は、LPの最初の説明で同じ言葉または意味で受ける
2. LPは「現在確認できるもの」「開発予定の体験」「最終的な事業構想」を混同しない
3. 見通し・調べ直し削減・準備支援・文化体験のどれを入口にしても、Core Valueである意思決定と準備へ接続する
4. 送客・提携は将来収益モデルとして説明できるが、未契約の提携、提供中の予約・購買機能、成果を示唆しない
5. 広告反応の高い表現をMissionへ自動昇格させない。変更境界は`P0-MKT-03`で定義する
