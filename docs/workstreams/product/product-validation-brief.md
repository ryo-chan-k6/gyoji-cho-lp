# Product Validation Brief

- Task ID：`P0-PROD-01`
- 版：v1.0（Validation Lead Review済み）
- 更新日：2026年8月16日
- 判断根拠：[`D-001 最優先ユーザー`](../../operations/decisions/d-001-primary-user.md)

## 検証する対象と課題

**Primary User**は、第一子の妊娠後期から、子どもが満1歳の誕生日を迎えるまでの家庭で、赤ちゃんの行事について主に情報収集・判断・準備を担う保護者である。行事を大切にしたい意向はあるが、時期・意味・やり方・準備内容に不慣れな人を初期獲得・検証で優先する。

「第一子」は利用資格ではない。第二子以降、祖父母、満1歳以降の家庭も利用を制限しないが、初期広告・主要KPI・インタビューの中心には置かない。

最初に解く課題は、**次に訪れる赤ちゃんの行事を先回りして知り、その意味と準備内容を理解して、やるつもりの行事を実行できるようにすること**である。

## 期間と利用場面

| 期間 | 主な状況・利用場面 | 期待する変化 |
|---|---|---|
| 妊娠後期 | 出産後の行事を意識し始め、必要な準備を見通したい | 出生後の行事体験を早期に認知し、利用を継続する理由を持つ |
| 出生後0〜11か月 | 次の行事が近づく、家族で実施を判断する、準備を始める、適切な時期に再確認する | 毎回調べ直さず、次の行事と意味・準備を理解して行動へ移る |
| 1歳の誕生日 | 満1歳までの初期体験を締めくくる | 一連の行事支援を体験し、初期Product Valueを評価できる |

妊娠後期の週数境界、予定日から出生後情報への移行方法、登録・通知等の具体的な実現機能は本Briefで決めない。

## 提供価値

| 区分 | 価値 | 検証上の位置づけ |
|---|---|---|
| Core Value | 子どもの情報から、必要な行事を先回りして知らせ、準備まで支援する | やるつもりの行事を、調査負担や準備遅れで実行できない課題を解く |
| Extended Value | 日本文化を知り、家族で体験する機会を提供する | 家族固有行事の間にも再訪理由と文化体験価値が生まれるかを検証する |

目指す体験は「知る」だけで終わらず、**先回りして知る → 意味を理解する → やるか考える → 準備・体験へ移る**までを途切れさせないことである。一方、文化体験を義務化して親の負担を増やさない。

## コホートの分離

- **妊娠期流入コホート**：出生後利用へ移行し、行事生成、Activation、Event-triggered Retentionへつながるかを追う。妊娠中には未発生の出生後行事があるため、出生後利用者と同じ主要Product KPI分母へ混在させない。
- **出生後流入コホート**：`D-001`に従い、出生後0〜11か月で実際の生年月日を登録した利用者をProduct Validationの主要判定母集団とする。
- サンプルが十分になった段階で、両コホートの**出生後Retention**を比較し、「妊娠期から流入した利用者は出生後の継続性が高い」という仮説を検証する。
- コホートの識別方法、許可する属性、必要母数、観測期間、KPI閾値は`D-007〜010`で決定する。正確な妊娠週数、予定日、生年月日はLocal-firstとし、Analyticsへ送信しない。

## 初期の対象外

- Web簡易MVPによるProduct Validation
- 一般的な妊娠・育児情報で既存総合サービスと競うこと
- 対象行事・季節文化の具体的な選定、件数、地域差の完全網羅
- 予定日登録、出生後更新、通知、準備CTA等の具体機能の採否
- 独自アカウント／バックエンド、決済、予約、提携店舗検索、本格商品推薦
- KPI閾値、必要母数、Analytics基盤、保持期間の確定
- Instagramの0〜5歳向け独立メディア戦略の変更、またはアプリ宣伝への転用
