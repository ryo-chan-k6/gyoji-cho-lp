## 目的と読み方

MLPで扱う家族固有行事、月齢マイルストーン、季節文化について、提供価値、時期・算出、意味・準備の範囲、通知候補、地域・家庭差、出典要件、MLP採否を一つの正本にまとめる。

- 本書は**対象コンテンツのスコープ**を固定する。画面、通知、チェック操作、「やってみる／今回はやらない」等の機能Must判定は`D-004`で行う
- 時期はプロダクト要件候補であり、公開用の確定日付・算出ロジックではない。P1-PROD-03でD-013準拠の根拠と境界日テストを持つ
- 通知時期は価値仮説を評価する候補であり、通知採用・回数・既定値を決定しない
- 「準備」は予約・購買・提携の提供を意味しない。家庭での判断と準備情報の範囲を示す
- 本書は公開コンテンツではない。各項目がD-013の`Human Approved`になるまで、記載をアプリ・広告・LPへ転用しない

### 家族固有行事の共通ルール

- 「一般的な目安」と「この家庭の予定日」を分け、ユーザーが日付を調整できる設計候補を`P0-PROD-03`へ渡す
- 行事を実施しない家庭を準備指標の失敗分母へ含めない。実施意向・見送り・未判断の扱いは`D-004/D-009`で固定する
- 予約、商品、寺社・店舗の在庫・営業、医療、安全を保証しない
- 同じ暦日に家族固有行事と季節文化が重なる場合、1つのContent Masterから家庭文脈を優先して表示する

### 季節文化の評価結果

- D-003の第一候補12件は、月1件、年間分散、乳児家庭との接点、D-013で管理可能な差異の観点からすべてMLP対象とする
- `SE-08`お盆は地域・宗派差、`SE-10`十三夜は認知・反応、`SE-11`七五三文化は0〜1歳への直接行動価値が主な不確実性である。採用はするが、P-04の事前定義した探索セグメントとしてSE-ID別に結果を残す。個別の支持・棄却を主張する場合は、`D-009`と`P0-VAL-03`でサブ仮説ID、分母、必要観測数、不明条件を実験前に固定する
- 候補の一部がP1のSource ResearchでD-013を満たさない場合、同じ月の代替候補へ入れ替える。総数12件・月1件を変える場合だけD-003の再判断を求める

| `V-02` 判断可能性 | 一般的目安・家庭／地域差の対象情報が表示され、閲覧機会があった利用者を起点にする | 閲覧後の家庭判断・後続行動と、非誘導の定性発言を接続する | 表示・閲覧だけで支持しない。未閲覧者・離脱者も理由確認の対象にする |
| `V-06` コンテンツ信頼 | D-013承認済みコンテンツが表示された対象を起点にする | 閲覧後行動、信頼・判断可能性の定性、訂正・問い合わせ・離脱を接続する | 問い合わせがないことだけで支持しない。未閲覧・早期離脱・母数不足は不明を許す |

共通の閾値、必要母数、観測窓、at-risk開始、テーマ統合条件は`D-009`と`P0-VAL-03`で固定する。登録時点ですでに通知候補期間を過ぎた利用者を通知不成功の分母へ入れない。初節句を翌年へ延期して満1歳のPrimary期間外になる場合は、P-03の当該FEについて「観測機会なし」とする。
