## 1. 目的と固定原則

本書は、Validation Releaseで作るものをMust / May / Won'tへ固定し、Phase 1中の自動的なスコープ追加を防ぐ正本である。対象は「薄い機能一覧」ではなく、次の価値連鎖を欠けさせない最小体験とする。

```text
妊娠期または出生後から利用開始
  → 家庭に合う行事を生成
  → 「つぎのお祝い」を知る
  → 意味と一般的な目安を理解
  → 家庭でやるか判断
  → 準備する
  → 通知で適切な時期に戻る
  → 月ごとの季節の行事にも出会う
```

- `Must`：Validation Releaseの価値または主要仮説の観測に不可欠。無承認で削減しない
- `May`：本Releaseでは**0件**。早期完了や余力を理由に追加しない
- `Won't`：画面、入口、空状態、将来予告、権限要求、専用Analytics、提供中訴求を含めて実装しない
- 日付計算・保存・通知等の方式は`D-006`、Analyticsは`D-007〜008`、分母・観測窓・閾値は`D-009`で固定する。本書はこれらを先取りしない

## 4. May

Validation ReleaseのMay機能は設定しない。次はMayではなく、Must内で変更できる**実装詳細**として扱う。

- レイアウト、アニメーション、説明順、アクセシビリティ改善
- 同じ受入条件を満たすコンポーネント・端末保存方式・通知方式。ただし方式は`D-006`確定後、そのDecisionと変更管理に従う
- P1 Usability Testで、既存Mustを完了可能にするための文言・操作改善

実装詳細の変更でも、データ項目、権限、第三者送信、コンテンツ対象、仮説分母、ユーザーへの約束を変える場合はMay扱いにせず、該当D-IDまたはFrozen Scopeを見直す。

## 6. 計測・データ・Legalの非機能境界

- 予定日、生年月日、性別の正確値、行事日、残り日数、細粒度月齢、初節句候補等の逆算・再識別可能な値をAnalyticsのイベント名・属性へ含めない
- 妊娠期／出生後等の粗粒度コホートの採否・定義・安全性は`D-007〜009`で決める
- Category IDを禁止値と結合送信せず、永続的な「関心プロフィール」を作らない
- CTAからアプリ内ガイドへの遷移は第三者送信を発生させない。外部送信は`D-007/008`で承認されたイベント・属性だけとする
- 端末内の属性、生成行事、家庭予定、選択、チェック、CTA／ガイド状態、予約済み通知は全削除の対象とする
- 外部Analyticsを`D-007/008`で採用する場合、保持期間、削除範囲・方法、利用者説明を`D-008`で固定する。端末内全削除が外部Analyticsの削除も意味すると誤認させず、画面・Privacy説明を実態と一致させる
- Product / Channel Validation、妊娠期／出生後、表示機会、実施判断、通知適格、観測窓未完了を混在させない。具体的なイベント・保持・分母・閾値は`D-007〜009`へ留保する

## 8. Phase 1開発上限と変更管理

| 項目 | Frozen条件 |
|---|---|
| 目標 | 8週間・責任者224時間 |
| ハード上限 | 10週間または責任者280時間の早い方 |
| 稼働 | 週28時間。前倒し余力を機能追加へ使わない |
| 追加開発費 | 0円。外注、有料SDK、有料バックエンド、新規有料開発ツールなし |
| 別判断 | Apple必須費用は`D-012`、広告費は`D-010`／`D-014` |
| 予測 | 週次・4週目に実績、残作業、未通過Gate、外部待ち、EACを更新 |
| 停止 | 上限超過見込みで新規実装を止め、10週／280時間の早い方へ到達する前にHuman Ownerへ提示 |

変更要求は次の順に処理する。

1. 既存Mustの受入条件を変えず、実装簡素化・再利用・順序変更で吸収できるか確認する
2. 期間・責任者時間・追加費用への影響と、Product / Data / Legal / Validationへの影響を見積もる
3. Must、対象コンテンツ、品質Gate、計測可能性、Privacy / App Store Gateへ影響する場合は新規実装を止める
4. 変更理由、代替案、EAC、失われる検証証拠、影響D-IDをDecision Packへまとめる
5. Human Ownerが該当D-IDと本Frozen Scopeを改定した後だけ着手する

AI PMやWorkstream Leadは、工数都合でMust、`D-002/003`対象、`D-013`品質、`D-007〜009`計測、Legal / Privacy / App Store Gateを削らない。上限到達時にGate未達なら未完成のまま停止し、品質や計測を落として完了扱いにしない。
